Aethel
------
The Aethel kernel is developed using a hybrid kernel architecture that prioritizes 
high performance and security—aiming for a security level comparable to that of Windows.
This kernel serves as the core of the Dust-OS operating system, managing hardware and
system resources while providing fundamental services for all other software.
